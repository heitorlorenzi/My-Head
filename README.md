## 🚀 Sobre o Projeto
O projeto utiliza **HTML5, CSS3, Bootstrap 5 e a biblioteca GSAP** para criar uma página interativa com animação de rotação em tempo real.

### ✨ Funcionalidades:
- **Tema Escuro Moderno:** Layout centralizado com efeito glassmorphism e iluminação neon.
- **Controles Interativos de Rotação (GSAP):**
  - ⏸️ **Pausar / Retomar:** Congela ou descongela a rotação da imagem.
  - 🐢 **0.5x:** Velocidade lenta.
  - ⚡ **1x:** Velocidade normal padrão.
  - 🚀 **3x:** Modo turbo de alta velocidade.
- **Rodapé com Links:** Acesso rápido ao perfil do GitHub, documentação e contato.

---

## 🌿 Estrutura GitFlow
O repositório foi organizado utilizando o modelo de branches do **GitFlow**:

```text
main (produção / GitHub Pages)
│
└── develop (integração)
    │
    ├── feature/personalizar-home (desenvolvimento da página e controles)
    │
    └── feature/github-pages (documentação, configuração e deploy)
```
